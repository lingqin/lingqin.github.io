零基础使用 GitHub + Hexo 搭建个人博客完全指南

欢迎开启个人独立博客的搭建之旅！本教程将带你从零开始，使用 Hexo（一个快速、简洁且高效的博客框架）和 GitHub Pages（免费的静态网页托管服务）搭建属于自己的个人博客。

一、 准备工作

在开始之前，请确保你的电脑上已经安装了以下工具：

  1. Node.js（Hexo 基于 Node.js 运行）：建议安装 LTS（长期支持）版本。
    • 验证安装：打开终端（Windows 的 cmd 或 PowerShell，Mac/Linux 的 Terminal），输入 node -v 和 npm -v，若能正常显示版本号则说明安装成功。
  2. Git（用于版本控制并将代码推送到 GitHub）：
    • 验证安装：输入 git --version。
  3. GitHub 账号：如果没有，请前往 GitHub 官网 免费注册一个。

四、 配置 GitHub 仓库与部署

1. 创建 GitHub Pages 仓库

  1. 登录 GitHub，点击右上角的 + 号，选择 New repository。
  2. Repository name 填写：你的用户名.github.io（例如你的 GitHub 用户名是 johndoe，仓库名必须严格写为 johndoe.github.io）。
  3. 选择 Public（公开）。
  4. 不要勾选 “Add a README file”（保持干净）。
  5. 点击 Create repository。

七、 进阶与美化建议

  • 更换精美主题：Hexo 默认主题比较简陋，你可以访问 Hexo Themes 官网挑选喜欢的主题（如 NexT、Fluid、Stellar 等），按照主题文档将其下载到 themes/ 目录并在 _config.yml 中启用。
  • 图床配置：建议使用 GitHub 仓库、Gitee 或第三方图床（如 SM.MS、PicGo）来管理博客中的图片，避免本地路径失效。
