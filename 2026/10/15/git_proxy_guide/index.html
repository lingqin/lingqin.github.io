开发者必备：如何优雅地开启、查询和关闭 Git 代理

在进行开源项目开发或从 GitHub 拉取代码时，网络问题常常会让人头疼。通过配置 Git 代理，我们可以顺畅地加速代码的克隆与拉取。本文将带你快速掌握如何针对全局或特定仓库配置、查看以及清理 Git 代理。

-–

一、 前提条件

在配置代理之前，你需要确认两件事：

  1. 本地代理软件已运行：例如 Clash、V2Ray、Shadowrocket 等。
  2. 代理软件监听的端口：默认通常是 7890、10809 或 10808（请根据你实际使用的软件设置进行调整）。

-–

  1. GitHub 走 SSH 协议不生效：
    本文介绍的 http.proxy 仅对 http:// 和 https:// 开头的仓库链接生效。如果你的远程仓库使用的是 git@github.com:... 这种 SSH 链接，需要通过修改 \~/.ssh/config 文件来配置 ProxyCommand。
